# Portal Publico

Aplicacao publica em Next.js para apresentacao institucional, artigos, eventos,
dicionario, documentos, media e conteudos ligados a plataforma linguistica.

## Requisitos

- Node.js 20 ou superior
- pnpm

## Instalar

```bash
pnpm install
```

## Desenvolvimento

```bash
pnpm dev
```

Para escolher uma porta:

```bash
pnpm dev -- -p 3002
```

## Build

```bash
pnpm build
pnpm start
```

## Qualidade

```bash
pnpm lint
```
